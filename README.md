# Daily Dose Of Wonder

build mobile app, that shows you intresting facts daily. every day different topic must be chosen to give people general knowledge about daily basis.
topics must be like:
how {{some topic}} works, for example(door key, car honk, car door window)
what {{some topic}} means, for example(what is credit score, how star borns and die)
